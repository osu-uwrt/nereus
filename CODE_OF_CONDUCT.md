# Community conduct

Treat contributors and users with respect. Discuss technical decisions and evidence,
not personal characteristics. Harassment, discrimination, threats, deliberate
intimidation, and publishing private information without consent are unacceptable.

Maintainers should explain decisions, acknowledge mistakes, and apply these
expectations consistently to code review, issues, documentation, and community
spaces. Address problems proportionately, from correction and mediation to removal
from a project space when necessary to protect participants.

During local development, report concerns privately to the project owner. A named
contact and appeal route must be established before opening a public community.
